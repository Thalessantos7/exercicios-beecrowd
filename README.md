# 💻 Exercícios Beecrowd

Repositório dedicado às minhas resoluções de problemas da plataforma [Beecrowd](https://judge.beecrowd.com/pt).

O objetivo deste projeto é documentar o meu progresso e evolução na plataforma, praticando o desenvolvimento de algoritmos, lógica de programação e consultas em bases de dados.

## 🗂️ Estrutura do Repositório

Os códigos estão organizados em diretórios distintos, separados pela linguagem de programação utilizada:

*   **`/java`**: Contém as soluções desenvolvidas em Java. O código-fonte encontra-se na pasta `src`, organizado por categorias da plataforma.
*   **`/sql`**: Contém os arquivos `.sql` com as consultas desenvolvidas para os desafios de banco de dados.

## 🚀 Tecnologias Utilizadas

*   **Linguagens:** Java, SQL.
*   **IDE:** IntelliJ IDEA.

## ⚙️ Como Executar

**Para os códigos em Java:**
1. Clone este repositório utilizando:
   `git clone https://github.com/Thalessantos7/exercicios-beecrowd`
2. Abra a pasta do projeto na sua IDE preferida (recomendado: IntelliJ IDEA).
3. Navegue até à pasta `java/src/` e execute o método `main` da classe correspondente ao exercício pretendido.

**Para os códigos em SQL:**
*   Copie o conteúdo do arquivo `.sql` pretendido e cole na sua ferramenta de gestão gráfica, ou envie diretamente na plataforma Beecrowd.
